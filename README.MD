# TW 2026 - Proiect 2: Ghidul Parcurilor și Atracțiilor din Botoșani

Proiect web dedicat prezentării principalelor zone de agrement, parcuri (Parcul Cornișa, Parcul Pacea, Lacul cu Nuferi), atracții culturale (Teatrul „Mihai Eminescu”) și personalități istorice din județul Botoșani.

## 🛠️ Tehnologii utilizate
- **HTML5** & **CSS3** (Design personalizat și modern, centrat pe nuanțe de verde natural)
- **Git / GitHub** pentru versionare și controlul codului sursă
- **VS Code** cu extensia Live Server

## 📂 Structura Proiectului
- `index.html` - Pagina de prezentare generală
- `history.html` - Istoricul orașului
- `how-it-works.html` - Ghidul timpului liber și atracții
- `notable-people.html` - Tabelul cu personalități marcante
- `css/style.css` - Fișierul de stiluri global
- `assets/images/` - Folderul care conține toate imaginile și resursele vizuale
